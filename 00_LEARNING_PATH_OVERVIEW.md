# Power BI Complete Learning Path – Levels 1 to 10
### From Absolute Beginner to Pre-Capstone

This is a full progressive curriculum designed for new Power BI students.

---

## Complete Path Overview

| Level | Project Name                    | Difficulty              | Focus Area                                      | Est. Time   |
|-------|---------------------------------|-------------------------|-------------------------------------------------|-------------|
| 1     | Coffee Shop Dashboard           | Absolute Beginner       | First dashboard, visuals, slicers               | 2–4 hrs     |
| 2     | Retail Store                    | Beginner                | Relationships + basic measures                  | 4–6 hrs     |
| 3     | E-commerce Analytics            | Beginner+               | Date table + Time Intelligence basics           | 5–8 hrs     |
| 4     | Retail Chain                    | Intermediate-           | Full star schema + multi-page report            | 8–12 hrs    |
| 5     | Intermediate Capstone           | Intermediate            | Multiple facts, light cleaning, targets         | 12–18 hrs   |
| **6** | **Sales Performance Analytics** | **Strong Intermediate** | Ranking, segmentation, moving averages          | 10–14 hrs   |
| **7** | **Multi-Fact Analysis**         | **Intermediate+**       | Sales + Returns + Inventory                     | 12–16 hrs   |
| **8** | **Advanced Features**           | **Advanced Intermediate** | RLS, Field Parameters, What-If, Targets       | 14–18 hrs   |
| **9** | **Complex DAX & Reporting**     | **Advanced Intermediate** | Advanced DAX, Drill-through, Tooltips         | 16–22 hrs   |
| **10**| **Pre-Capstone (VoltEdge)**     | **Advanced**            | Full scenario, data quality, 4 facts, RLS       | 20–30 hrs   |

---

## Learning Journey

**Foundation (Levels 1–3)**  
Learn the Power BI interface, basic visuals, relationships, and time intelligence.

**Core Skills (Levels 4–5)**  
Build proper models and handle multiple fact tables.

**Advanced Skills (Levels 6–9)**  
Master ranking, complex DAX, RLS, field parameters, inventory, returns, and professional report design.

**Pre-Capstone (Level 10)**  
Experience a realistic business scenario with data quality issues — the final preparation before the full **Voltora Electronics Capstone**.

---

## Recommended Pace
- Levels 1–3: 1 week
- Levels 4–5: 1–2 weeks
- Levels 6–8: 2–3 weeks
- Levels 9–10: 2–3 weeks

Total estimated focused practice: **100–150 hours**.
