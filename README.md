# Power BI Learning Projects – Levels 1 to 10
### Complete Progressive Curriculum for New to Advanced Students

This package contains **10 complete Power BI projects** that take a student from absolute beginner to pre-capstone level.

---

## Quick Navigation

| Levels | Stage                        | Description                                      |
|--------|------------------------------|--------------------------------------------------|
| 1–3    | Foundation                   | First dashboard → Time Intelligence              |
| 4–5    | Core Intermediate            | Star schema + Multiple facts                     |
| 6–9    | Advanced Intermediate        | Ranking, RLS, Complex DAX, Inventory, Returns    |
| 10     | Pre-Capstone                 | Realistic multi-fact project with data quality   |

---

## Folder Structure

Each Level contains:
- `Data/` → All required CSV files
- `Documentation/PROJECT_BRIEF.md` → Full instructions, required measures, business questions

Start with: `00_LEARNING_PATH_OVERVIEW.md`
